# Business Requirements

## Executive Summary

The Enterprise SOC Lab was designed to satisfy the operational and security requirements of the fictional organization LOROINC. These requirements guided the selection of technologies and the overall infrastructure design.

---

# Business Goals

The environment must:

- Provide centralized authentication.
- Secure business data.
- Support multiple departments.
- Enable centralized administration.
- Provide enterprise networking.
- Support cybersecurity monitoring.
- Be scalable and maintainable.

---

# Functional Requirements

The infrastructure must provide:

- Active Directory Domain Services
- DNS
- DHCP
- Enterprise networking
- Windows client management
- Linux server administration
- Containerized applications
- Security monitoring
- Log collection
- Threat detection

---

# Security Requirements

The environment must support:

- Strong password policies
- Group Policy enforcement
- Security Groups
- User authentication
- Endpoint monitoring
- SIEM integration
- Security event logging
- Account auditing

---

# Infrastructure Requirements

The solution must include:

- VMware Workstation
- Windows Server 2022
- Windows 11 Enterprise
- Ubuntu Server
- Docker
- Portainer
- Wazuh
- OPNsense Firewall

---

# Operational Requirements

The environment should be:

- Easy to manage
- Well documented
- Highly organized
- Easily reproducible
- Suitable for troubleshooting
- Appropriate for training purposes

---

# Success Criteria

The deployment is considered successful when:

- Users authenticate successfully.
- Clients join the domain.
- DNS resolves correctly.
- DHCP assigns addresses.
- Docker services run normally.
- Wazuh agents report successfully.
- Security events are collected.
- Threat Hunting displays endpoint activity.
