# Company Background

## Executive Summary

LOROINC is a fictional technology company created to provide a realistic enterprise environment for the Enterprise SOC Lab. The company serves as the business context for the infrastructure deployed throughout this project, allowing technical decisions to align with organizational requirements and common enterprise practices.

The Enterprise SOC Lab simulates the design, deployment, administration, and security monitoring of a small-to-medium business IT environment.

# IT Infrastructure

LOROINC operates a hybrid enterprise infrastructure consisting of:

- Windows Server 2022
- Active Directory
- DNS
- DHCP
- Windows 11 Enterprise
- Ubuntu Server
- Docker
- Portainer
- Wazuh SIEM
- VMware Workstation
- OPNsense Firewall

---

# Security Strategy

The organization follows several security principles:

- Least Privilege
- Centralized Authentication
- Group Policy Enforcement
- Endpoint Monitoring
- Security Event Collection
- Continuous Monitoring

---

# Project Purpose

The Enterprise SOC Lab was developed to simulate the IT infrastructure of LOROINC and provide practical experience with enterprise technologies used in modern organizations.
